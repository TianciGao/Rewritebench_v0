# Benchmark Spec

This directory contains public v0 benchmark-scope policy documents for SQL-RewriteBench.

Documents:

- `scope.md`: public v0 benchmark scope and non-goals.
- `case_package_contract.md`: case package surface and manifest-governed metadata.
- `denominator_policy.md`: Common-core v0 membership and Track A denominator policy.
- `reporting_policy.md`: role-aware and denominator-aware reporting boundaries.

These documents do not compute metrics, render paper tables, update reports/results, change denominator membership, or create a leaderboard.
