# PERF_0052

Clean-template-minimal v2 case package for pool `PERF`.

## SQL

- Source SQL: `sql/source.sql`
- Positive rewrite: `sql/pos_01.sql`
- Negative rewrite: `sql/neg_01.sql`

## Schema

The case-local schema surface is profile-first. `schema/schema_profile.yaml` is the case-facing profile, and executable DDL/load assets are externalized under `schemas/tpcds_perf0052_v0/`.

## Checker

`checker/` stores configuration only. Shared checker implementation belongs under `src/sql_rewrite_bench/`; this case package does not contain per-case Python checker implementations.

## Validation

`validation/run_validation.sh` and `validation/run_plan_collection.sh` are thin v2 wrappers. They do not create case-local run outputs, do not compute official metrics, and do not render report or leaderboard artifacts.

## Witness

Runtime checking uses source-as-oracle policy. Static witness result files are optional and are not required for the runtime checker.

## Evidence Policy

Static case evidence is not required for clean v2. Evidence can be regenerated by validation/checker/baseline/report scripts when those shared runners are authorized.

## Benchmark Boundary

This conversion does not change case membership, denominator eligibility, paper results, official metrics, reports, results, or leaderboard outputs.

## Source Family

- Source family: `TPC-DS`
- Schema package: `schemas/tpcds_perf0052_v0/`
