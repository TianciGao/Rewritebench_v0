# Boundary Wording Review

`docs/baseline_reproduction.md` includes the required boundary phrases:

- "local diagnostic reproduction"
- "No paper-facing metric is promoted"
- "No global leaderboard is produced"
- "Performance is interpreted only over exact+timed rows"
- "PG40 cannot fill Track A 120"
- "Do not fabricate missing candidates"
- "Do not commit output/"

The manual also states that outputs should use D035-style output roots and that top-level `reports/` and `results/` remain protected official/paper surfaces.

The manual does not describe POCR as official and does not authorize paper-facing metric promotion, retained-evidence promotion, or leaderboard creation.
