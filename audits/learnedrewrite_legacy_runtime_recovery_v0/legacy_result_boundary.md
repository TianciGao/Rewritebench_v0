# Legacy Result Boundary

Old LearnedRewrite evidence is legacy context only.

- Old LearnedRewrite outputs may guide wrapper setup, schema-shape planning, response-field extraction, and bounded evidence interpretation.
- Old outputs must not be imported as new canonical metrics.
- Old timing or checker results must not be mixed into current `local_metrics.py` outputs.
- Old bounded PG10 evidence must remain appendix/bounded legacy evidence unless a separate promotion task is authorized.
- Any future new result must be regenerated through the D035 user facade and then, if appropriate, summarized through `python -m cli.main user compute-local-metrics`.
- No old result, old request log, old generated SQL, old runtime output, or old metrics file was copied into the release repo as canonical output in this task.

The legacy paper-freeze files repeatedly mark LearnedRewrite as bounded PG-only, summary-only, or `UNKNOWN_NOT_RECOVERED` for formal route-level evidence. That is a setup signal, not a denominator-complete current-route result.
