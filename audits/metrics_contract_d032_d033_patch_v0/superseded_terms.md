# Superseded Terms

- Attribution Coverage is historical/superseded relative to current paper-facing Positive Operation Coverage Rate. It may appear only as support-context wording if separately labeled.
- Speedup Retention is historical/superseded relative to current paper-facing Cross-Engine GM Speedup Ratio.
- Executed-denominator Result Consistency is superseded by canonical `Result Consistency Rate = exact / selected`.
- Regression@20 is not formal local metrics v0. It may remain only as a separately labeled legacy/reporting diagnostic.
- Candidate Failure Rate is not a primary metric; failure buckets remain diagnostic/support only.
- Observability / PlanFrontier are support/diagnostic only and do not replace POCR.
