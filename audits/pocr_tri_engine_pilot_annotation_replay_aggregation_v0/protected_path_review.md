# Protected Path Review

Protected-path review for the tri-engine pilot:

- no `cases/` files modified: confirmed by git status checks.
- no `skills.md` modified: confirmed by git status checks.
- no candidate SQL modified: confirmed by git status checks.
- no `runs/user` modified: confirmed by git status checks.
- no `output/` staged or committed: verified before commit.
- no `/tmp` output staged or committed: verified before commit.
- no top-level `reports/` or `results/` modified: confirmed by git status checks.
- no denominator changed: no case set or denominator manifest changed.
- no case membership changed: no `case_sets/` files changed.
- no paper results changed: no paper-facing reports/results changed.
- no raw legacy evidence changed: no legacy/raw evidence files changed.

This is not official POCR. No route-level official POCR score is emitted. No paper-facing metric is promoted.
