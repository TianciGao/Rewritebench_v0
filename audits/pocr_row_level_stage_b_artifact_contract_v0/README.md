# POCR Row-Level Stage B Artifact Contract v0

This defines a row-level artifact contract only.

This is not official POCR. No route-level official POCR score is emitted. No paper-facing metric is promoted.

No experiment is run. No live API call is made. No API key is read. No annotation JSONL is generated. No user replay, DB/checker/timing run, baseline rerun, candidate SQL generation, or candidate SQL mutation occurs.

POCR@planned and POCR@candidate remain D039 promotion views. POCR@curated remains deferred / `curated_manifest_missing`.

The contract defines durable row-level Stage B metrics as the future input surface for promotion-safe POCR aggregation.
