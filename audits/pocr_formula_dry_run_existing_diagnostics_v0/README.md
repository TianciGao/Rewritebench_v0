# POCR Formula Dry Run Existing Diagnostics v0

This is a no-API formula dry-run over existing Repair-1 PG40 and SQLGlot no-op PG40 diagnostic artifacts.

This is not official POCR. No route-level official POCR score is emitted. No paper-facing metric is promoted.

POCR@planned and POCR@candidate are tested as D039 promotion views. POCR@curated remains deferred until a predeclared curated manifest exists. It is reported as `curated_manifest_missing`.

The dry-run uses existing row-level replay artifacts only. It does not call an API, read API keys, generate annotation JSONL, rerun user replay, run DB/checker/timing, rerun a baseline, generate or mutate candidate SQL, update top-level reports/results, promote retained evidence, or create a leaderboard.
