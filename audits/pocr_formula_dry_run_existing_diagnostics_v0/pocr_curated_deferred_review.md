# POCR Curated Deferred Review

POCR@curated is not computed in this dry-run.

No predeclared curated denominator manifest exists for this promotion process, so POCR@curated remains deferred until a predeclared curated manifest exists.

The current paper formula is preserved as the curated-subset formula. A future POCR@curated value can be calculated only from a frozen curated denominator manifest and Stage-B-supported row evidence.

The curated subset must not be invented after the fact from generated, executed, exact, timed, or otherwise successful rows.

This is not official POCR. No route-level official POCR score is emitted. No paper-facing metric is promoted.
