# Low-Risk Skeleton Plan

This plan lists metadata skeleton files that can be created later without changing scientific claims, denominator membership, paper results, metrics, reports/results content, retained evidence, or leaderboard policy.

Do not execute this plan until a separate metadata-only task is authorized.

## Benchmark Spec Skeleton

- `benchmark_spec/README.md`: index for public benchmark scope and links to policy files.
- `benchmark_spec/scope.md`: Common-core v0 scope, pool split, Track A same-engine denominator, and explicit non-goals.
- `benchmark_spec/case_package_contract.md`: public case package unit and required package files.
- `benchmark_spec/denominator_policy.md`: denominator-aware reporting and membership governed by `case_sets/common_core_v0/`.
- `benchmark_spec/reporting_policy.md`: role-aware reporting, no global leaderboard, no SpeedupTransferRate for current evidence, no performance interpretation without exact + timed rows.

## Documentation Index

- `docs/README.md`: concise index linking user benchmark guide, user-entry data flow, run artifact policy, and future benchmark spec.

## Reports / Results Boundary Placeholders

- `reports/README.md`: state that no paper reports are generated by user-entry commands and that reports are only added under separate authorization.
- `results/README.md`: state that no official results are computed by user-entry commands and that retained or paper-facing results are only added under separate authorization.

## Optional Output Hygiene Skeleton

- `.gitignore`: narrow root-level ignores for Python caches, pytest caches, local virtual environments, and local run outputs while preserving tracked audit and retained surfaces.

## Validation for Future Skeleton Task

- `git diff --check`
- Markdown heading sanity checks
- Protected-surface diff check
- No source/scripts/tests/cases/case_sets/reports data/results data changes beyond placeholder README files
- No metrics, paper rendering, retained-evidence promotion, release tag, or export branch
