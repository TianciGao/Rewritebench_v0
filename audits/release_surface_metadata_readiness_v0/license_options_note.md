# License Options Note

This note is informational only. It does not choose a license.

## Permissive Code Licenses

- Apache-2.0: permissive license with explicit patent grant and notice requirements. Common for research software when patent clarity matters.
- MIT: short permissive license with minimal conditions. Simple but lacks an explicit patent grant.
- BSD-3-Clause: permissive license with attribution and non-endorsement clause. Common in academic software.

## Documentation / Data Licenses

- CC-BY-4.0: allows redistribution and adaptation with attribution. Often used for documentation and data when commercial use is allowed.
- CC-BY-NC variants: restrict commercial use. This may limit adoption and compatibility with some downstream uses.

## Mixed-License Possibility

The project may choose one license for the whole repository or separate notices for code, documentation, and benchmark data. Mixed licensing must be stated clearly to avoid ambiguity for benchmark users.

## Required Decision

A maintainer/team decision is required before creating `LICENSE`. Do not infer license terms from dependencies, README wording, or repository visibility.
