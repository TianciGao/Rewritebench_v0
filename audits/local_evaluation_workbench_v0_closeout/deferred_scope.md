# Deferred Scope

The following work is explicitly outside local evaluation workbench v0 closeout:

- official metrics computation;
- retained-evidence promotion;
- paper table rendering;
- reports/results migration;
- leaderboard output;
- release/export/tag creation;
- POCR implementation;
- skill folder creation;
- operation atom inference;
- exactness-changing label policy;
- broader Common-core reruns;
- new timing collection;
- official timing evidence promotion.

## POCR / Skill Adapter

POCR remains deferred under D032. No `skill/` folders, operation atom files, or operation atom inference should be created until the collaborator external script and schema are reviewed and separately authorized.

## Official Metrics / Retained Evidence / Paper Rendering

The non-official local metrics calculator is local diagnostic tooling only. It does not authorize official metrics, retained-evidence promotion, reports/results updates, paper table rendering, or leaderboard output.

## Label Policy

The strict label policy remains in force. Label-only mismatches remain mismatches and timing-ineligible unless a future case-, role-, or config-gated policy is separately authorized.
