# A-line Denominator And Caveat Package

## Fixed Public v0 Scope

- Common-core v0 contains 40 canonical case packages.
- Track A same-engine denominator contains 120 planned case-engine rows.
- Rewrite-candidate scaffold contains 600 planned rows across five method routes.
- Control scaffold contains 360 planned control rows.

## Denominator Rules

Denominator reduction is forbidden. Authorized, unresolved, unauthorized, blocked, N.A., and post-release partitions must remain visible in any future renderer.

The two limited official status metrics use denominator-aware outputs. Existing limited official status outputs record 600 planned candidate rows, 175 authorized status input rows, and 425 unresolved or unauthorized rows.

No global leaderboard is allowed.

## Controls Caveat

Hard negatives are checker controls. They are not rewrite-method failures and must not be folded into method numerator or denominator partitions.

## Metric Caveats

Execution Coverage Rate and Result Consistency Rate are limited official status metrics only. They are not paper results until a separate renderer task is authorized.

Generation Rate is blocked for v0. The current inferred-generated evidence remains audit-only and SQLGlot generated/ready evidence is incomplete.

Semantic Equivalence Rate is support-only for v0. Verifier references are not an official semantic-equivalence numerator or denominator.

GM_Speedup and Speedup Ratio Percentiles are blocked for v0. Timing/performance metrics are not available in this A-line v0 package.

Speedup Retention is N.A. for v0 because paired source/target result-consistent timing is unavailable.

Attribution Coverage, Cross-Engine Execution, and Cross-Engine Consistency are post-release backlog metrics.

## Renderer Requirements

Future renderer outputs must display blocked, N.A., audit-support, and post-release metrics as such. The renderer must not hide missing denominators, unresolved rows, or unsupported metric families. It must not convert this package into paper tables without separate authorization.
